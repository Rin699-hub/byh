

Byh Browserは、C# (Windows Forms) と Microsoft Edge WebView2 を使用して作成された、シンプルで軽量なデスクトップ Web ブラウザです。

---

## 🌟 主な機能

- **Web ブラウジング機能**
  - Microsoft Edge (Chromium) エンジンを搭載し、高速で快適な表示に対応。
  - URL の直接入力、およびキーワード検索に両対応。
- **操作ナビゲーション**
  - 「←（戻る）」「→（進む）」「更新」ボタン搭載。
  - Enter キーによるページ移動・検索実行。
- **画面自動フィット**
  - ウィンドウサイズ変更や最大化を行っても、各ボタンやアドレスバーが崩れず自動調整されます。
- **カスタマイズ可能な設定機能 (⚙️)**
  - **起動時ページ設定:** アプリ起動時に開くデフォルト URL を自由に変更可能。
  - **検索エンジンの切替:** Google / Yahoo! JAPAN / Bing / DuckDuckGo から選択可能。
  - **閲覧データの削除:** キャッシュ、Cookie、閲覧履歴をワンクリックで消去。
  - **設定の永続化:** 変更した設定は `settings.txt` に自動保存され、次回起動時にも維持されます。

---

## 💻 動作環境

- **OS:** Windows 10 / 11 (64-bit)
- **ランタイム:** 
  - .NET 8.0 SDK / Runtime 以降
  - Microsoft Edge WebView2 Runtime

## 🚀 使い方

### 基本操作
1. **ページを開く / 検索する:**
   - アドレスバーに URL（例: `https://www.google.com` や `yahoo.co.jp`）を入力して **Enter** キーまたは **「移動」** ボタンを押します。
   - 検索ワード（例: `プログラミング`）を入力して実行すると、設定されている検索エンジンで検索されます。
2. **ページ移動:**
   - **←** : 前のページに戻ります。
   - **→** : 次のページに進みます。
   - **更新** : ページを再読み込みします。

### 設定の変更 (⚙️)
1. 画面右上の **「設定」** ボタンをクリックします。
2. **起動時に開くページ** の URL や、使用する **検索エンジン** を選択します。
3. **「保存して閉じる」** を押すと、設定が `settings.txt` に保存されアプリが終了します。次回起動時から設定が反映されます。
